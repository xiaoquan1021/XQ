# 视觉基线:旧 XQ(MITK 版)vs 新 XQ(gui-v2)真机对比

> 2026-07-04 用户提供两张截图(打开同一工程 0007_H_AO_H)。原图在用户手里,
> 此文档记录可供文字对照的全部差异点。新接手者做 M1~M5 验收时逐项对照。

## 旧 XQ(MITK 版)——功能基线,要对齐的目标

标题栏 `XQ — Cardiovascular Analysis Suite [28 nodes]`。

1. **四视图**:Axial(红框)/ Sagittal(绿框)/ Coronal(蓝框)/ 3D(黄框),
   三个切片格全部有图像,图像按各自平面正确 reslice 显示。
2. **切片上叠加分割/轮廓**:Axial 与 Coronal 图像上有绿色轮廓线(contour 节点),
   Sagittal 上有绿色填充的分割区域——**图像与派生物合成渲染**。
3. **3D 视图合成**:三张正交切片平面(红/绿/蓝边框标识)+ 绿色血管分割体
   在 3D 空间中共同显示,可旋转。
4. **十字线**:每个切片格有全幅正交十字线(红/绿/蓝按轴配色),交点即当前位置。
5. **数据管理器**:树形(Widgets / 0007_H_AO_H 分组),节点前有**勾选框**控制显隐;
   下方 Opacity 滑块(100%)、Color 按钮、Properties 折叠面板。
6. **Image Navigator**:Loc.(mm) 三个坐标 spin(0.81/0.50/3.44)+
   Axial/Sagittal/Coronal 滑块+索引 spin(255/53/255)。
7. **窗宽窗位色阶条**:右侧有灰度校准条(0~3000 刻度)+ 两个数值框(1112/3014)。
8. **状态栏**:`Position: <0.81, 13.60, 20.88> mm; Time: 0.00 ms  495.67 MB (3.05%)`
   + 绿色状态灯 + `Position: Ready` + 右下 `Nodes: 28`。
9. 工具栏:Open/Save Workspace ‖ Undo/Redo ‖ Image | Path | 2D Seg | 3D Seg |
   Model | Mesh | Simulation。
10. 中央区有 `Standard Display` 标签页(可关闭的 tab)。

## 新 XQ(gui-v2)——同工程打开后的实况(缺陷清单)

1. **Axial 有图但比例异常**(窄条置中),**Sagittal 全黑、Coronal 全黑**
   (仅角标 51/100、257/512 显示切片号在走)。
2. **切片上没有任何轮廓/分割叠加**——工程里 5 个 path、5 个 contour、surface、
   mesh 节点全部只躺在列表里。
3. **3D 格完全空白**(只有一个 "3D" 角标)。
4. 十字线只有细蓝线,无轴配色、观感弱。
5. 数据管理器是**平铺表格**(名称/类型/状态三列),状态列显示 `false` 但
   **勾选框缺失、可见性不接渲染**;无 Opacity/Color/Properties(07-03 B2 删了)。
6. 图像导航器只有三个滑块+spin;无 Loc 坐标(B2 删了)。
7. 无窗宽窗位控件、无色阶条。
8. 状态栏:`已加载项目:14 个节点` + `内存 522 MB` + `节点:0`
   ——**节点计数互相矛盾**(左 14、右 0;旧版 28),另注意旧版 28 节点 vs 新 reader
   读出 14 节点,疑似 SV 工程读取覆盖面差异,M3 时要查清。
9. 交互:**整体卡顿远超 MITK 版**(用户原话:特别特别卡),滑块拖动迟滞。

## 验收映射(哪个模块修哪条)

| 缺陷 | 模块 |
|---|---|
| Sagittal/Coronal 黑、Axial 比例异常、卡顿 | M1+M2(常驻管线+正确 reslice) |
| 无叠加、3D 空白 | M1+M3(可见性合成) |
| 勾选框/Opacity/Color 缺失 | M3 |
| 无窗宽窗位交互 | M2 |
| Loc 坐标、Position 状态栏 | M4 |
| 节点计数矛盾、28 vs 14 节点 | M3(查 SvProjectReader 覆盖面) |
| 色阶条 | M2(可后置,与用户确认优先级) |
