# Google Earth 式数字孪生壳 A：验收矩阵

## 1. 用途与范围

本矩阵是壳 A 的放行依据。壳 A 只证明：真实医学影像能够进入 XQ 数据脊柱；导航几何、截面证据与求解几何职责分离；稳定领域契约可以被真实求解器消费；数据血缘、失效、保存重开和能力关闭均可重复验证。

壳 A 不以画面完整度或单次演示成功作为通过标准。下表每一行的正路径、负路径、持久化、自动测试和人工门必须同时满足；“不宣称事项”是发布说明和 GUI 文案的硬边界。

测试层级缩写：

- `UT`：纯 C++ 单元测试。
- `IT`：跨 core/service/io 的无 GUI 集成测试。
- `E2E`：从真实输入到结果入库、保存重开的端到端测试。
- `GUI`：人工或 Qt 自动化界面验证。

## 3. 全局硬门

壳 A 只有在以下条件全部成立时才能标记完成：

1. 矩阵中所有自动测试通过，且不存在依赖测试顺序或人工修改 fixture 才能通过的用例。
2. DICOM、Profile、assembler、smoke、保存重开和 Flow OFF 的人工门均由操作清单重复完成。
3. 任一负路径都产生稳定诊断代码，并证明没有半节点、半 asset、部分 SolverInput 或错误结果提交。
4. 源数据发生 semantic edit 后，下游 stale；undo/redo 与保存重开不会破坏 revision 和 stale 状态。
5. `VesselProfileV1` 是唯一求解几何；GUI 和 solver 不再直接从 Contour 临时拼装面积，也没有散落的 mm/cm 转换。
6. 发布说明、GUI 标签、截图和演示口径遵守“不宣称事项”，特别是将血流结果明确标为 `L0 geometry smoke`。
7. 达到上述门槛后立即停止扩大壳 A，后续能力作为独立“芯”任务接入。
