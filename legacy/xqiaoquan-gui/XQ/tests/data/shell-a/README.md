# Shell A historical Flow fixture

`history-flow-v1.xqproj` is a non-clinical, metadata-only project fixture used
by the `XQ_ENABLE_FLOW=OFF` acceptance test. Its `VesselProfile`,
`SimulationCase`, and complete `FlowResult` series were generated by the
production `VesselProfileController -> FlowGeometrySmokeService ->
FlowSolver1D` chain in `test_shell_a_e2e`; no test solver or fabricated success
result is used.

Regenerate deliberately from an ON Release build:

```powershell
$env:XQ_SHELL_A_HISTORY_FIXTURE_OUT = `
  "$PWD/XQ/tests/data/shell-a/history-flow-v1.xqproj"
ctest --test-dir XQ/build_gui -C Release --output-on-failure `
  -R '^test_shell_a_e2e$'
Remove-Item Env:XQ_SHELL_A_HISTORY_FIXTURE_OUT
```

The fixture contains no DICOM files, patient identifiers, source paths,
screenshots, or PHI. It is history-only evidence; an OFF build must preserve
and display it but must not execute a new smoke solve.
