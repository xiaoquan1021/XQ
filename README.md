# XQ consolidated source archive

This repository is a source and research archive assembled from the two local
working trees that were previously stored on the C: drive:

- `legacy/xiaoquan/` from `C:\Users\OCEAN\Desktop\XIAOQUAN`
- `legacy/xqiaoquan-gui/` from `C:\Users\OCEAN\Desktop\XQIAOQUAN-gui`

The two trees remain separate so that their histories, build entry points and
research notes cannot overwrite one another. The new whole-body vascular twin
work continues in `D:\work\whole-body-vascular-twin`.

## Deliberately excluded

The public repository does not contain patient imaging, model weights,
generated results, build trees, installed SDKs, dependency download caches,
virtual environments, or runtime binaries. Those files are machine-local and
must be recreated from the dependency manifests.

The source trees retain their original documentation and source layout. Their
legacy `.git` directories are not nested into this archive.
