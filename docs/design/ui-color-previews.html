对比总结：
• 方案A (午夜蓝宝石)：最专业的科研风格，深蓝+青色让人联想到天文/医学成像软件。WCAG AAA 对比度。
• 方案B (暖石墨)：最具差异化，暖色调石墨灰+橙色在医学软件中非常罕见，个性鲜明。
• 方案C (北极浅色)：最干净清爽，适合临床环境。浅色主题但与 SV 用色完全不同（灰白 vs SV的浅蓝）。
• 方案D (当前)：深靛蓝+琥珀金，如果觉得丑可能需要调整色彩饱和度和对比层次。

推荐：方案A 或 方案B 兼顾专业感和差异化。方案C 如果更喜欢浅色主题。
